Introduction

I work on knowledge-augmented LLM applications, agent systems, and self-evolving agents. I focus on connecting language models with external knowledge and tools, then improving long-horizon execution through reflection, supervision, and replanning.

Knowledge-Augmented LLMs

Grounding language models in external knowledge for professional and real-world applications.

Agent Systems

Designing runtimes, workflows, and multi-agent systems for reliable tool use and task execution.

Self-Evolving Agents

Improving agents through tool synthesis, trajectory rectification, harness training, and adaptive replanning.
